OSTROG: every file it puts on your computer, and what it is
===============================================================

This guide lists each file and folder Ostrog makes, in plain words: what
it is for, whether it is ever sent anywhere, and whether you can delete it.
The same list is in the game: Settings, then "Your files and data".


THE OSTROG FOLDER
-----------------
Where: wherever you unpacked Ostrog

  ostrog-launcher.exe
    The program you double-click. It checks our server for a newer version,
    downloads updates, and starts the game. It shows you what it is doing at
    every step.
    Sent anywhere? It asks our server for the version list and the update; it
    sends nothing about you or your game. Our server's web log sees your IP
    address and the time, like any website
    Safe to delete? Not unless you are uninstalling

  launcher.toml
    The launcher's settings: the address of our update server, the public key
    it uses to check that an update really came from us, your version, and
    whether to check for updates. You can read it in Notepad. Setting
    check_enabled = false turns update checks off.
    Sent anywhere? No
    Safe to delete? No (the launcher needs it)

  README.md, VERSION
    The project's read-me (today the full developer README, about 0.6 MB) and
    the version of this build.
    Sent anywhere? No
    Safe to delete? Yes

  READ ME FIRST.txt
    This guide in plain text.
    Sent anywhere? No
    Safe to delete? Yes

  app/
    The game itself. Every update replaces this folder completely, so never
    keep your own files in it. Contains ostrog.exe (the game program),
    ostrog.pck (the game's art, sounds and scripts), hf_godot.dll (the game's
    simulation engine) and copies of README.md and VERSION.
    Sent anywhere? No
    Safe to delete? Only if you are uninstalling

  data/
    The launcher's own folder. logs/launcher.log is a plain diary of what the
    launcher did ("checked for updates", "downloaded version X", "you
    cancelled the download"); it stays on your computer and grows by about
    half a kilobyte each time you start Ostrog. .keep is an empty placeholder.
    Sent anywhere? No
    Safe to delete? The log, yes. Leave the rest

  .ostrog-update/
    Used during an update: the new version being unpacked, and a copy of your
    previous version so an update that fails to start can be undone. Emptied
    once the new version has started; the empty folder may stay.
    Sent anywhere? No
    Safe to delete? Yes, when no update is running


YOUR SAVED GAMES AND SETTINGS
-----------------------------
Where: %APPDATA%\Godot\app_userdata\Ostrog\ (type that into the Explorer
       address bar)

  settings.cfg
    Your options: sound, interface scale, camera and so on.
    Sent anywhere? No
    Safe to delete? Yes (options reset)

  announce.cfg
    Which alerts you chose to see or pause on.
    Sent anywhere? No
    Safe to delete? Yes

  saves/
    Your saved games: the rolling autosaves (auto.0.hfsave to auto.2.hfsave)
    and your manual save (manual.hfsave). Each save is a folder holding
    world.bin, chronicle.sqlite and manifest.json; it is written first as
    <name>.hfsave.tmp so a half-written save never replaces a good one. While
    a save is being written the folder also holds .ostrog-save-writing, a tiny
    marker the launcher looks for so an update never starts mid-save; it
    disappears when the save is done.
    Sent anywhere? No
    Safe to delete? No: this is your game. Delete only to start over

  logs/
    The game engine's own diary, godot.log, used to find crashes. The engine
    also keeps a few older ones from earlier launches, named
    godot<date>T<time>.log, and removes the oldest itself.
    Sent anywhere? No
    Safe to delete? Yes

  shader_cache/
    The engine's store of graphics programs it has already prepared for your
    graphics card, so the next start is quicker (under 1 MB).
    Sent anywhere? No
    Safe to delete? Yes (rebuilt on the next start)

  ostrog-debug.log
    A detailed record of why each person did what they did. Only written when
    debug mode is on. It grows quickly (about 6 MB in four minutes at the
    fastest speed); at 32 MB it is renamed ostrog-debug.log.1 and a new one
    starts, so the two together never pass about 64 MB.
    Sent anywhere? No
    Safe to delete? Yes

  timelapse/
    Only if you turn Timelapse on: one picture of the valley at noon each game
    day, with a small note of what happened, kept per world so you can watch
    it grow. At most 120 pictures and 160 MB per world, for at most 6 worlds
    (about 1 GB in the worst case); the oldest are removed first.
    Sent anywhere? No
    Safe to delete? Yes (you lose the time-lapse)


TEMPORARY FILES
---------------
Where: in your Windows temporary folder, %TEMP%

  ostrog/
    While a game is open, the valley's history is kept in a working file here
    (chronicle-<number>.sqlite, with -wal and -shm companions) instead of in
    memory; your saves copy it. The game removes the file when it closes and
    clears any left over from a crash on a later start. The empty folder
    stays.
    Sent anywhere? No
    Safe to delete? Yes, when the game is not running

  ostrog-archive-*.zip.part
    While the launcher downloads an update: the part-downloaded file, checked
    before anything is installed and removed when the launcher has finished
    with it. If the launcher is closed in the middle of a download, the part
    file stays until you delete it.
    Sent anywhere? No
    Safe to delete? Yes, when no update is running
