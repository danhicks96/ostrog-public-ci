# Decisions

This file is the record of decisions that shape the game or the work. It is append-only. The only edit allowed to an existing row is setting its Status to `superseded by Dnn`, and the new row Dnn must say which row it supersedes. Anything else that changes is a new row at the bottom.

Who is `Dan` or the role of the agent that made the call. An agent's own judgement call is added with Status `proposed`. It stays in force until Dan accepts or overrules it, and a `Dan` row outranks a `proposed` one. Status values are `accepted` (Dan decided), `proposed` (an agent decided, Dan has not reviewed), `in force` (older rows where the decider was not recorded) and `superseded by Dnn`.

Log a decision only if it was contested, is not obvious from the code, or is one a future agent could undo by mistake. For a contested decision, fill `Rejected / revisit if` with the options that were turned down and the evidence that would reopen it. A product constraint that is not visible in the code must be written here.

Rows D1 to D69 predate the Who and Status columns. Where a row names Dan, Who is `Dan` and Status is `accepted`. For every other old row Who is `?` and Status is `in force`, because the decider was not recorded and is not guessed.
