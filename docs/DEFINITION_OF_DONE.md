# Definition of done

The release is done only when every row of the acceptance matrix is **verified** with the
evidence listed. Status values: `incomplete` (default), `partial` (some behaviour, missing
integration, presentation or verification; the row says what), `blocked` (reason recorded),
`deferred` (explicit, written in ROADMAP.md as a deferral, never counts as done), `verified`.

A subsystem test passing advances a row; it never completes one. Completion requires working
behaviour, integration into the running game, appropriate presentation, and verification.

## Standing requirements (re-assessed every phase in the glance review)

- Visually between Animal Crossing's warmth and high-definition RimWorld/DF mods, with clear
  activity at normal second-monitor viewing distance; “higher fidelity” never excuses noise or
  loss of readability.
- Objects, equipment and clothing are understandable as physical things with parts, condition
  and history; unknown history is shown as unknown.
- The default experience stays active when the viewer is absent; no modal prompts ever.
- Off-screen inhabitants remain the same people (DECISIONS D10).
- History is recorded, never invented (D9); audited by `chronicle_only_real_events` from Phase 11.
- A production art checkpoint is incomplete without runtime use, provenance, focused guards and
  integrated-game evidence; a design mockup is not an asset delivery.
- A person's displayed reaction must be explainable by their observations, appraisal, relationships,
  needs, traits and memories, not by an omniscient global solver.

## Performance and stability targets (provisional until measured; see docs/TIME.md)

| Metric | Target |
|---|---|
| Local map / overworld | 256×256×24 z / 64×64 sites |
| Population | 500 active inhabitants + 100 animals on the local map |
| Tick time at 500 inhabitants | mean ≤ 2 ms, p99 ≤ 10 ms (10×); ≤ 16 ms (3×); ≤ 50 ms (1×) |
| Planner | ≤ 32 plans per tick, amortised ≤ 50 µs; A* ≤ 2,000 expansions, hierarchical beyond 64 tiles |
| Client | 60 fps at 1920×1080, frame apply ≤ 4 ms |
| Memory | sim RSS ≤ 2 GB after 600 game-days (24 h at 10×), growth explained by recorded history (D16); chronicle ≤ 500 MB per 100 game-years |
| Soak | 24 h × 4 seeds at 10×: 0 deadlocks, stalled < 1 %, no oscillation flags, no save corruption |
| Save | ≤ 150 MB; write ≤ 1 s off-thread; load ≤ 3 s |

Targets are revised only in writing, in STATUS.md, with the measurement that justified it, and
never by lowering the experience requirements.
